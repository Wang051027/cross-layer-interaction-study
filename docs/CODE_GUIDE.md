# 从设想到代码的阅读顺序

最新的三组组合规则、留出条件预测和阻断验证见 [LATEST_EXPERIMENT.md](LATEST_EXPERIMENT.md)。下面介绍 9 月 29 日版本的基础定义。10 月以来新增的梯度、通道组合、上游恢复、组外背景与下游阻断脚本均列于 [完整源码索引](SCRIPT_INDEX.md)。

1. **明确要解释的量。** `source/scripts/joint_response.py` 把一次干预组合看成布尔立方体上的一个点，用空、单点和成对响应构造预测。`run_demo.py` 直接用真实缓存响应演示低阶预测何时失效。
2. **把“层间关系”定义成条件交互。** `cross_layer_mechanism.py` 的 `design` 生成 16 个组合与 24 个差分；`pair_difference` 计算背景条件下的二阶有限差分。稳定仿射映射产生零差分，跨越 ReLU 状态可能产生非零差分。
3. **逐层追踪计算。** 同一文件的 `trace` 和 `decomposition` 复用模型权重与残差连接，区分固定基线门控下的传播和非线性修正。分量之和重建输出交互是一项代数核验，不自动构成语义机制发现。
4. **用干预检验传递。** `dsprites_mechanism.py` 的 `patch` 在完整 block2 输出上执行恢复和移植。`project` 定义 margin／中心化向量目标，`contrasts` 定义交互；`finite_scores` 根据真实单点修补评分。
5. **控制替代解释。** `run_dsprites_mechanism.py` 按开发、冻结、逐图半强度选点、冻结、完整强度评价的顺序执行；比较全局固定、按类别固定、逐图、随机、完整可达池等方案。
6. **理解输入和模型。** `prepare_dsprites.py` 下载固定官方源、按因素整组划分、排除跨集合精确像素重复并构造严格平移。`dsprites_teacher.py` 重训六个三类模型，仅用验证损失选权重。模型块定义在 `residual_teacher.py`。
7. **独立核验。** `test_*` 提供已知答案与原 `forward` 钩子对照；`audit_dsprites_results.py` 用另一种差分矩阵和投影运算重算全部结果。`run_checks.py` 是本仓库新增的、不依赖私有档案的核验入口。

本轮评价中，四个源坐标均位于 block1，同一个中介集合位于 block2。这里的“跨层”指组合效应从源层到后层的传递，不表示每次都在多层各挑一个源神经元。

常用数组：`natural[图,组合,类]`；`patched[图,方案,恢复或移植,组合,类]`；`contributions[图,非线性阶段,差分,类]`。差分共享原始输出，不能把每张图的 24 个差分当成 24 个独立样本。

两项主要比率分别是恢复后剩余交互 RMS／原交互 RMS，以及移植交互与原交互之差的 RMS／原交互 RMS。都越低越好；原交互接近零时应留空，不能把无定义比率当成零。
