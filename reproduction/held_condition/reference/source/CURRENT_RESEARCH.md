# 神经元组合与跨层机制研究当前进度

## 2026年11月1日　留出条件下预测三组交互

在原36幅dSprites图内冻结了一条相邻层组合规则。12个大小×角度条件分为6个开发格和6个留出格，每格使用三个循环方向的形状配对。全强度主检验在每个模型上有72条三组记录，六模型共432条。另用同一套名单和参数复测了半强度。

四通道阈值修正在六个模型上都改善了完整block2三阶响应，教师等权的误差比为0.884。输出三阶差分的误差比为1.003，阻断所选四通道为1.044，只保留它们为0.969。预设四项检验中只有中间层通过。按形状转换及三组编号从开发格取得的均值，预测输出三阶作用的误差比为0.619。

全强度下，阻断与只保留四通道的实际带符号作用在124/432条记录上方向相反。当前读出给两种操作相同的预测值。事后将真实中间层三阶响应代入空组梯度时，四通道和全32通道的输出误差比分别为0.961和0.851。本轮支持在留出条件上预测部分中间层组合响应，对整条输出传递规则的检验未通过。

## 当前结论

原组合的输出作用分布在多个下游通道和空间位置。单个恢复开关不能解释整体作用；保持开启的位置上的幅度变化同样重要。联合阻断之后，剩余输出可进一步分为未阻断卷积分支、直接残差支路，以及末层读出的正负抵消。不能把小净余量直接等同于传播路径已消失。

这里C效应指整组通道从匹配背景的C-off替换为C-on造成的条件输出差，包含可加部分，并不等于纯高阶交互项。F仍为供体类别减受体类别logit。旧背景比较00→10，新背景比较01→11。报告主表使用新背景b=F11−F01；旧固定例b=2.920629，完整上游干预F11−F00则为3.371569，两者不能混用。

## 队列与阻断定义

继承全部26条严格定向恢复记录（15个状态、5个有成功的模型），加4个仅分解对照、每模型首个非空失败源干预共6条、原参照依赖失败例1条，合计37条案例×方法记录。记录之间共享输入，不作为37个或26个独立样本。

在block3第一和最后ReLU后，各定位32768个位置及32个整通道。阻断是恢复选中位置在同组外背景C-off的实际非负值；第一层阻断后第二ReLU真实重算。同时做只保留选中变化、残差支路off/on两版本。末层之后只剩GAP和线性读出，其可加性是结构恒等式。

按绝对单点输出差定位，整通道按实际整通道阻断差定位；全部37条两背景两层名单先封存，再评估联合阻断。固定点预算1/4/16/64/256/1024、通道预算1/2/4/8/16/32，候选不足截断。各两组随机名单使用同变化候选池与预算。定位由同案例输出指导，属于探索，不是独立泛化验证。

## 具体证据

固定例教师292/案例70/mask15/端点25，C=(7,9)，原j=(2,11,17)。第一ReLU最强四个整通道为2、18、13、6；末层重要通道为26、0、29、14。两层各自定位，未证明第一通道与末层通道的一一专属连边。

第一层最强单点是(2,13,9)，保持开启、幅度改变，移除效应0.054351；原j仅移除0.004414。前256点联合移除2.165198、剩0.755431；单点移除之和2.025327，非加和差0.139871。前4通道联合移除2.384155、剩0.536474。主26条的前256点联合差均非零，不能以单点之和代替联合阻断。

主记录按教师内RMS比例、再对5个非空教师等权：原j阻断剩99.18%，最大单点97.99%，最多256点37.63%，随机同预算93.49%/93.19%，最多1024点10.17%，最多4通道43.36%，最多8通道18.97%。这些量不是逐案例因果解释百分比；点与整通道成本也不同。

固定例卷积分支单独3.002188、残差支路单独−0.081384、两路交互−0.000175，总C效应2.920629。全部第一层变化阻断后恰剩−0.081384，再恢复残差支路则为0。主26条均存在非零残差支路效应；跨教师剩余RMS比例8.35%。

前256点阻断后的0.755431，由残差支路单独−0.081384和该背景下剩余卷积条件效应0.836815合成。末层正余量1.026518、负余量−0.271087。主要正余量通道为0、26、29、14，主要负余量通道包括10、1、19、12；最大绝对余量位置(7,14,10)贡献−0.003297。

前8通道阻断后净余量仅0.041664，但正余量0.338584、负余量−0.296921仍在。小净值包含显著抵消。空间正负与通道正负分组不同，通道内也可能抵消，不把通道和空间数值混加。

第一层最强单点19/26未翻转，末层26/26未翻转。阻断全部第一层翻转位置仍剩85.98%的RMS量级，阻断全部稳定开启幅度变化则剩29.37%。集合大小不同，这不是等预算优劣比较，而是说明只研究翻转不足以解释输出传递。4条仅分解对照的C效应全为0。
